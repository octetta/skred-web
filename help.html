Skred WASM Integration Example

This is a minimal example demonstrating how to embed the Skred WebAssembly engine into a web application. The code blocks below show the exact JavaScript running on this page.

1. Required Files

To run Skred in the browser, you need to grab three files from the wasm build directory in the github.com/octetta/pulp repository and host them together:

  • skred_api.js - The high-level API wrapper
  • skred_core.js - The Emscripten JS glue code
  • skred_core.wasm - The compiled DSP engine binary

For a complete list of audio commands you can send to the engine, see the Skode User Command Reference.

2. Engine Lifecycle

Load the script and initialize the audio engine with a buffer size and max voices.

HTML & JavaScript

<script src="skred_api.js"></script>

// Start engine with 128 frames and 256 max voices
Module._skred_start(128, 256, 0);

// Stop engine and release audio device
Module._skred_stop();

3. Send Commands & Read Output

Send a string to the engine using Emscripten's ccall, then poll for text output.

JavaScript

// Enable command logging
Module.ccall('skred_command', null, ['string'], ["log 1"]);

// Execute an arbitrary command
Module.ccall('skred_command', null, ['string'], ["v0 f440 a0 l1"]);

// Read the text response
const ptr = Module._skred_log();
const response = ptr ? Module.UTF8ToString(ptr) : "";
